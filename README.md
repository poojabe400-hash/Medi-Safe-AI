# MediSafe AI
http://localhost:3000/(Project URL)

## Predictive Medical Inventory Management System

MediSafe AI is an AI-powered clinical inventory management dashboard designed to help medical stores and healthcare facilities monitor medicine stock, identify critical shortages, analyze consumption patterns, and predict potential stockouts.

The system provides a centralized dashboard for inventory monitoring, stock forecasting, alerts, analytics, medicine management, and administrative operations.
